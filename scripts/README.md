# MCWB Scripts

This directory contains diagnostic, demonstration, and verification scripts for the MeshCore Weather Bot (MCWB) project.

## Script Categories

### Diagnostic Scripts
- `diagnose_announcement.py` - Diagnose announcement functionality
- `diagnose_channels.py` - Diagnose channel communication

### Demo Scripts
- `demo_hashtag_channels_work.py` - Demonstrates hashtag channel functionality
- `demo_invalid_channel_fix.py` - Demonstrates invalid channel handling
- `demo_usb_detection.py` - Demonstrates USB port detection
- `demo_user_scenario.py` - Demonstrates typical user scenarios

### Verification Scripts
- `FIX_VERIFICATION.py` - Verifies specific fixes
- `manual_verification.py` - Manual verification procedures
- `verify_channel_filtering_fix.py` - Verifies channel filtering functionality
- `verify_frame_code_fix.py` - Verifies frame code handling

## Running Scripts

Run scripts from the project root:

```bash
python3 scripts/demo_usb_detection.py
python3 scripts/diagnose_channels.py
```

All scripts include inline documentation explaining their purpose.
