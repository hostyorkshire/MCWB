Learn more about the Web Dashboard →

🔧 Debug Mode

Comprehensive logging for troubleshooting:

python3 weather_bot.py --debug

Shows:

  • All protocol frames between bot and radio
  • Channel index information for received messages
  • Message processing flow
  • API requests and responses
  • Channel filtering decisions

🎯 Flexible Command Formats

The bot recognizes multiple command formats (case-insensitive):

wx London
weather London
WX LONDON
wx York, UK
wx Paris FR

🚀 Auto Port Detection

The bot automatically detects your USB serial port:

python3 weather_bot.py  # Auto-detects port

Or specify manually:

python3 weather_bot.py --port /dev/ttyUSB0 --baud 115200

🔒 Channel Filtering (Optional)

For advanced users who want to restrict the bot to specific channels:

# Only respond on channel index 1
python3 weather_bot.py --channel-idx 1

# Configure announcement channel
python3 weather_bot.py --weather-channel-idx 2 --announce

Note: Most users don't need this! The bot works automatically on all channels.

🌐 Default Country Filtering

If most users are in one country, set a default to prefer local cities:

# Prefer UK cities
python3 weather_bot.py --country GB

# Prefer US cities
python3 weather_bot.py --country US

Users can still override by specifying country in their command: wx York USA

MeshCore Protocol Support

The bot implements the MeshCore companion radio binary protocol:

Frame Direction Description
CMD_APP_START (0x01) → radio Initialize session on connect
CMD_GET_DEVICE_TIME (0x05) ← radio Radio requests time; bot responds
CMD_SYNC_NEXT_MSG (0x0A) → radio Drain queued messages
CMD_SEND_CHAN_MSG (0x03) → radio Send weather reply on channel
RESP_CHANNEL_MSG (0x08/0x11) ← radio Incoming channel message
PUSH_CHAN_MSG (0x88) ← radio Inline push of channel message
PUSH_MSG_WAITING (0x83) ← radio New message queued

For complete protocol details, see the API Documentation.

Deployment Options

1. Interactive Mode

Run in your terminal for testing:

python3 weather_bot.py --interactive

2. Background Process

Run in background without systemd:

nohup python3 weather_bot.py > weather_bot.log 2>&1 &

3. Systemd Service

Professional deployment with auto-start:

./install_service.sh
sudo systemctl start weather_bot

4. Docker (Community)

Docker support is community-maintained. See GitHub issues for containerized deployments.

🍓 Raspberry Pi Optimization

The bot is specifically optimized for Raspberry Pi Zero 2 and other Pi models. It's lightweight, efficient, and perfect for headless deployments in remote locations.
