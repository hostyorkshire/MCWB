Basic Installation

Update Your System

sudo apt-get update
sudo apt-get upgrade -y

Install Python and Git

sudo apt-get install -y python3 python3-pip git

Clone the Repository

cd ~
git clone https://github.com/hostyorkshire/MCWB.git
cd MCWB

Install Python Dependencies

python3 -m pip install -r requirements.txt

This installs:

  • requests - For API calls to Open-Meteo
  • pyserial - For USB serial communication with radio
  • Flask - For the web dashboard (optional)

Verify Installation

python3 weather_bot.py --location London

If this returns weather data, you're all set!

The bot is optimized for Raspberry Pi, especially the Pi Zero 2 for lightweight deployments.

Raspberry Pi Zero 2 Setup

Quick Pi Installation

sudo apt-get install -y python3 python3-pip git

git clone https://github.com/hostyorkshire/MCWB.git

# Install Python packages
python3 -m pip install -r requirements.txt

# Test installation
python3 weather_bot.py --location Leeds

Running as a systemd Service

For production deployments, run the bot as a systemd service that starts automatically on boot.

Method 1: Automated Installation (Recommended)

cd ~/MCWB
./install_service.sh

The script will:

  • Configure the service for your user and paths
  • Install it to systemd
  • Enable auto-start on boot
  • Optionally start it immediately

Method 2: Manual Installation

Copy Service File

sudo cp weather_bot.service /etc/systemd/system/

Edit Service File

sudo nano /etc/systemd/system/weather_bot.service

Update the following fields:

  • User=pi → Change to your username
  • WorkingDirectory=/home/pi/MCWB → Update path
  • ExecStart=/usr/bin/python3 /home/pi/MCWB/weather_bot.py → Update path

Enable and Start Service

sudo systemctl daemon-reload
sudo systemctl enable weather_bot
sudo systemctl start weather_bot

Check Status

sudo systemctl status weather_bot

View logs:

sudo journalctl -u weather_bot -f

Web Dashboard Setup

The bot includes a beautiful dark-themed web dashboard for monitoring.

Dark Theme Dashboard

Monitor your bot in real-time with:

  • Real-time status monitoring
  • Log viewer with color-coded entries
  • Auto-refresh every 10 seconds
  • Responsive design for all devices

Quick Start Dashboard

# Start the dashboard
python3 web_dashboard.py

# Access at: http://localhost:5000

# For network access:
python3 web_dashboard.py --host 0.0.0.0

Dashboard as a Service

# Install dashboard service
./install_dashboard_service.sh

# Start dashboard service
sudo systemctl start mcwb-dashboard
sudo systemctl enable mcwb-dashboard
