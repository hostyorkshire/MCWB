⌨️ How to Use the Bot

Open your MeshCore app or client and send a weather command on any channel:

wx London
weather Manchester
wx York UK

The bot will reply with current weather conditions instantly!

✨ Zero Configuration Required

The bot automatically works on any channel without needing to configure channel IDs! Just run it and start using it on any channel you've created.

Overview

MCWBv2 (MeshCore Weather Bot) is a lightweight Python3 weather bot designed for MeshCore mesh networks. It provides real-time weather information to users on your mesh network by responding to weather queries with current conditions from the free Open-Meteo API.

🎯 Works on ANY Channel

The bot is NOT limited to any specific channel. It works on:

  • ✅ ANY channel name you create in your MeshCore app
  • ✅ #weather, #wxtest, #forecast, #sensors - whatever you want!
  • ✅ ALL your channels simultaneously by default
  • ✅ Zero configuration needed - just run it!

Key Features

  • Automatic Channel Adaptation - Works on all channels simultaneously
  • Country Specification - Specify country codes to disambiguate locations (e.g., wx York UK)
  • Real-time Weather Data - Current conditions including temperature, humidity, wind, and precipitation
  • Multiple Command Formats - Supports wx, weather, and WX commands
  • Periodic Announcements - Optional bot announcements every 3 hours
  • Web Dashboard - Monitor bot activity with a beautiful dark-themed interface
  • Systemd Service Support - Run as a background service with auto-start on boot
  • Debug Mode - Comprehensive logging for troubleshooting

How It Works

The bot connects to a MeshCore companion radio (ESP32/LoRa device) via USB serial connection. It listens for weather commands from users on the mesh network, fetches current weather data from the Open-Meteo API, and broadcasts the response back on the same channel.

📡 LoRa Radio Hardware

MCWBv2 connects to a MeshCore companion radio over USB serial. The companion radio is a LoRa-based device (e.g., T-Beam, LILYGO LoRa32, or similar ESP32/LoRa board) running the MeshCore firmware.
