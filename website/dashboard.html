🌙 Full-Featured Dashboard

This is a demo showing the types of data you can monitor. For real-time monitoring with actual bot data, use the included Web Dashboard:

python3 web_dashboard.py --host 0.0.0.0

The web dashboard includes:

  • Real-time log streaming
  • Actual bot status monitoring
  • Color-coded log entries
  • Multiple log file views
  • Auto-refresh functionality

Connecting to Real Dashboard

To view live data from your running bot:

Start the Bot

python3 weather_bot.py

Start the Dashboard

python3 web_dashboard.py --host 0.0.0.0

Open in Browser

Navigate to: http://localhost:5000

Or from another device: http://[your-pi-ip]:5000
