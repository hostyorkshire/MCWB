Want to see live data from your bot?

Option 1: Cloudflare Tunnel (Recommended)

Connect this website to your bot without port forwarding:

  1. Run on your Raspberry Pi (adjust path if needed): 
    cd ~/MCWB && ./install_cloudflare_tunnel.sh
  2. Follow the setup wizard (requires free Cloudflare account)
  3. You'll get a URL like: https://dashboard.yourdomain.com
  4. Update website/js/dashboard.js with your tunnel URL
  5. Deploy changes - this page will show live data!

Full Guide: See CLOUDFLARE_TUNNEL_SETUP.md for detailed instructions.

Option 2: Local Network Access

Access dashboard on your local network only:

  1. Start the dashboard on your Pi: 
    python3 web_dashboard.py --host 0.0.0.0
  2. Access from any device on your network: 
    http://192.168.1.109:5000

Option 3: DDNS with Port Forwarding

Traditional remote access (requires router access):

  1. Set up DDNS service:
    • No-IP (Free Dynamic DNS)
    • DuckDNS (Free & Simple)
  2. Configure port forwarding on your router (port 5000 → 192.168.1.109)
  3. Access your dashboard from anywhere: 
    http://your-hostname.ddns.net:5000

Learn More: See WEB_DASHBOARD.md for complete setup instructions.

Access Live Dashboard on Your Raspberry Pi

To view real-time data from your running bot, access the web dashboard directly on your Raspberry Pi:

Step 1: Start the Bot

python3 weather_bot.py

Step 2: Start the Web Dashboard

python3 web_dashboard.py --host 0.0.0.0

Step 3: Access Locally

On the same device: http://localhost:5000

From another device on your network: http://[your-pi-ip]:5000

Find your Pi's IP: hostname -I

Remote Access Setup (DDNS / No-IP)

Want to access your dashboard from anywhere, not just your local network? Set up Dynamic DNS:

Step 1: Choose a DDNS Provider

  • No-IP - Popular free option with easy setup
  • DuckDNS - Simple and free, no registration needed
  • Dynu - Free with multiple hostname options

Step 2: Install DDNS Client on Your Pi

Follow your provider's instructions to install their update client. For No-IP:

cd ~
wget https://www.noip.com/client/linux/noip-duc-linux.tar.gz
tar xzf noip-duc-linux.tar.gz
cd noip-2.1.9-1/
sudo make install
sudo noip2

Step 3: Configure Port Forwarding

Log into your router's admin panel and forward port 5000 to your Raspberry Pi's local IP address.

Example: Port 5000 → 192.168.1.109:5000

Step 4: Access Your Dashboard Remotely

You can now access your dashboard from anywhere:

http://your-hostname.ddns.net:5000

Security Note: Consider setting up HTTPS with SSL certificates for secure remote access. See HTTPS_SETUP.md for instructions.
