Commands & Usage

Complete reference for all weather bot commands and command-line options.

Basic Usage on MeshCore

Open your MeshCore app and type:

wx [location]

Example: wx London, wx Manchester, wx New York

User Commands (MeshCore App)

These are the commands users send on the MeshCore app to query weather:

Basic Weather Query

wx London
London, GB
Partly cloudy
Temp: 14.2°C (feels 12.8°C)
Humid: 72%
Wind: 18 km/h at 230°
https://mcwb.netlify.app

Alternative Command Format

weather Manchester

Both wx and weather work identically. Commands are case-insensitive.

Specify Country

For cities that exist in multiple countries, specify the country:

wx York UK
York, GB (United Kingdom)
wx York USA
York, US (United States)
wx Paris FR
Paris, FR (France)

Traditional Format

You can also use comma-separated format:

wx York, UK
weather Paris, France

Command-Line Options

Options for running the weather bot script:

Connection Options

Option Description Example
-p PORT
--port PORT		 Serial port (auto-detects if omitted) --port /dev/ttyUSB0
-b BAUD
--baud BAUD		 Baud rate (default: 115200) --baud 115200

Mode Options

Option Description Example
-d
--debug		 Enable debug output python3 weather_bot.py -d
-i
--interactive		 Interactive mode (no radio) python3 weather_bot.py -i
-l LOCATION
--location LOCATION		 Quick lookup and exit (no radio) --location Leeds

Channel Options

Option Description Example
-c CHANNEL_IDX
--channel-idx		 Only respond to this channel index --channel-idx 1
-w WEATHER_CHANNEL_IDX
--weather-channel-idx		 Channel index for announcements --weather-channel-idx 2

Feature Options

Option Description Example
-a
--announce		 Send periodic announcements every 3 hours --announce
--country COUNTRY Default country code for geocoding --country GB

Usage Examples

Standard Operation

# Auto-detect port, work on all channels
python3 weather_bot.py

With Debug Logging

# See all protocol messages and processing
python3 weather_bot.py --debug

With Announcements

# Send reminder announcements every 3 hours
python3 weather_bot.py --announce

Specify Port

# Explicitly set serial port and baud rate
python3 weather_bot.py --port /dev/ttyUSB0 --baud 115200

UK Deployment

# Prefer UK cities by default
python3 weather_bot.py --country GB --announce

US Deployment

# Prefer US cities by default
python3 weather_bot.py --country US

Testing Without Radio

# Interactive testing
python3 weather_bot.py --interactive

# One-shot query
python3 weather_bot.py --location "New York"

# Debug mode interactive
python3 weather_bot.py --interactive --debug

Advanced Channel Configuration

# Only respond on channel index 1
python3 weather_bot.py --channel-idx 1

# Announce on channel 2, respond on all channels
python3 weather_bot.py --weather-channel-idx 2 --announce

# Both announce and respond only on channel 2
python3 weather_bot.py --channel-idx 2 --weather-channel-idx 2 --announce

Country Codes Supported Example

Command Patterns

The bot matches these patterns (case-insensitive):

Pattern Matches Examples
wx <location> Yes wx London, WX manchester
weather <location> Yes weather York, WEATHER leeds
wx <location> <country> Yes wx York UK, wx Paris FR
wx <location>, <country> Yes wx York, UK, wx New York, USA
wxLondon (no space) No Must have space after command
weather (no location) No Must specify a location
what's the weather No Must use wx or weather prefix

MeshCore Send Utility

The repository includes meshcore_send.py for sending messages programmatically:

Basic Send

# Send message via connected radio
python3 meshcore_send.py "wx London"

Specify Channel

# Send on channel index 1
python3 meshcore_send.py "wx London" --channel-idx 1

# Send by channel name
python3 meshcore_send.py "wx London" --channel weather

Simulation Mode

# Test without radio hardware
python3 meshcore_send.py "wx London" --node-id testnode

Service Management Commands

When running as a systemd service:

Start/Stop/Restart

# Start the service
sudo systemctl start weather_bot

# Stop the service
sudo systemctl stop weather_bot

# Restart the service
sudo systemctl restart weather_bot

Enable/Disable Auto-Start

# Enable auto-start on boot
sudo systemctl enable weather_bot

# Disable auto-start
sudo systemctl disable weather_bot

Check Status and Logs

# Check service status
sudo systemctl status weather_bot

# View recent logs
sudo journalctl -u weather_bot -n 50

# Follow logs in real-time
sudo journalctl -u weather_bot -f

Tips

  • Commands are case-insensitive: wx, WX, Wx all work
  • Location names are flexible: Handle spaces and special characters
  • Country codes work in any position: wx York UK or wx UK York
  • Bot responds on the same channel where the command was sent
