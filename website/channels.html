Channel Configuration

Understanding how channels work with the MeshCore Weather Bot.

✨ Zero Configuration Required

For most users: You don't need to configure anything! The bot automatically works on ALL channels simultaneously and responds on the same channel where each request came from.

Table of Contents

  • Channel Overview
  • Automatic Channel Adaptation
  • Setting Up Channels

Channel Overview

MeshCore supports channel-based broadcasting, allowing organized communication streams across your mesh network.

What are Channels?

Channels are named communication streams that help organize messages:

  • #weather - Weather updates and forecasts
  • #wxtest - Weather testing
  • #forecast - Forecast information
  • #general - General communication
  • Any name you want! - Create custom channels

Channel Index

Every channel is associated with a numeric channel index (0-7):

Index Description Security
0 Default/public channel Well-known PSK (public)
1-7 Named channels (#weather, #wxtest, etc.) Unique PSK (encrypted)

Automatic Channel Adaptation

The bot's default behavior requires no configuration:

How It Works

  • ✅ Listens on ALL channels for weather commands
  • ✅ Responds on the SAME channel where each request came from
  • ✅ Adapts announcements to use the channel that users are active on

Example Scenario

Different users have #weather mapped to different indices:

  • User A's device: #weather → channel_idx 1
  • User B's device: #weather → channel_idx 2
  • User C's device: #weather → channel_idx 3

Bot behavior:

  • User A sends "wx London" on channel_idx 1 → Bot replies on channel_idx 1
  • User B sends "wx Paris" on channel_idx 2 → Bot replies on channel_idx 2
  • User C sends "wx Berlin" on channel_idx 3 → Bot replies on channel_idx 3
  • All users get responses on their respective channels automatically!

Setting Up Channels

⚠️ Critical: Configure Channels in MeshCore App

Before the bot can receive messages, you MUST configure channels on your radio using the MeshCore mobile app. The bot cannot add channels for you.

Open MeshCore App

Launch the MeshCore app on your phone or tablet.

Connect to Radio

Connect to your companion radio via Bluetooth or USB.

Open Channel Settings

Navigate to Channel Settings in the app.

Add Channels

Join/subscribe to channels you want the bot to monitor:

  • #weather
  • #wxtest
  • #forecast
  • Or any custom channel names

Save Configuration

Save your changes and disconnect from the radio.

Start the Bot

Now start the bot - it will receive messages on all configured channels!

python3 weather_bot.py

Advanced Configuration

Most users don't need these options, but they're available for advanced scenarios.

When to Use Channel Filtering

Use channel filtering when you want to:

  • Isolate the bot to a dedicated weather channel only
  • Run multiple bots and prevent conflicts
  • Have explicit control over which channel the bot uses

Don't use channel filtering if:

  • Running a typical deployment (just use default behavior)
  • Users might have #weather on different channel indices
  • You want maximum flexibility

Option 1: Basic Channel Filtering

# Only respond to messages on channel index 1
python3 weather_bot.py --channel-idx 1

Option 2: Announcement Channel Configuration

# Send announcements on channel 2, respond to all channels
python3 weather_bot.py --weather-channel-idx 2 --announce

# Both announce and respond only on channel 2
python3 weather_bot.py --channel-idx 2 --weather-channel-idx 2 --announce

Finding Your Channel Index

Remember: You usually don't need to find this! The bot works automatically.

Method 1: Check MeshCore App

Look at Channel Settings in your MeshCore app to see which slot #weather is assigned to.

Method 2: Use Debug Mode

python3 weather_bot.py --debug

Send a test message on #weather and observe the channel_idx in output:

[17:45:32] channel_idx=2 SomeUser: wx test

Channel Security

🔒 Encrypted Channels

In MeshCore, hashtag channels (channels 1-7) are encrypted using channel-specific Pre-Shared Keys (PSKs):

  • Channel 0 (default/public) - Uses well-known PSK (effectively public)
  • Channels 1-7 (#weather, #wxtest, etc.) - Use unique PSKs for encryption

Only devices with the correct PSK can send or receive messages on encrypted channels.

Best Practices

  • Keep it simple: For most deployments, just run python3 weather_bot.py
  • Use descriptive names: #weather, #forecast, #wxtest
  • Configure radio first: Always set up channels in MeshCore app before starting bot
  • Reply on same channel: Bot automatically does this
  • Don't overuse channels: Too many channels can be confusing
  • Test thoroughly: Use --debug mode to verify channel operation
