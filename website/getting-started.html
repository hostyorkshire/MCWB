Getting Started

Get up and running with the MeshCore Weather Bot in just a few steps!

⌨️ Using the Bot on MeshCore

Once the bot is running, simply open your MeshCore app or client and send:

wx London

The bot responds instantly with current weather conditions on the same channel!

Prerequisites

What You'll Need

  • Raspberry Pi (Zero 2, 3, 4) or any Linux/macOS/Windows PC
  • MeshCore companion radio (ESP32/LoRa device with MeshCore firmware)
  • USB cable to connect the radio
  • Internet connection
  • Python 3.7 or higher

Quick Setup

Clone the Repository

git clone https://github.com/hostyorkshire/MCWB.git
cd MCWB

Install Dependencies

pip install -r requirements.txt

This installs requests and pyserial libraries.

Connect Your Radio

Connect your MeshCore companion radio to your computer via USB. The device typically appears as:

  • /dev/ttyUSB0 or /dev/ttyACM0 on Linux
  • COM3 or similar on Windows
  • /dev/cu.usbserial-* on macOS

Run the Bot

python3 weather_bot.py

The bot will auto-detect the serial port and start listening for commands!

Configure Channels (Critical Step)

⚠️ Important: Configure Your Radio First

Before running the bot with your radio, you must configure which channels it should monitor using the MeshCore mobile app:

  1. Open the MeshCore app on your phone/tablet
  2. Connect to your companion radio
  3. Go to Channel Settings
  4. Join/subscribe to channels you want the bot to use:
    • Common examples: #weather, #wxtest, #forecast
    • You can add multiple channels
  5. Save your configuration

Why this matters:

  • The bot cannot add channels for you
  • Without this step, the bot won't receive messages from those channels
  • This is a one-time setup (unless you want to add more channels later)

Test the Bot

Method 1: Test with MeshCore App

  1. Ensure the bot is running (python3 weather_bot.py)
  2. Open your MeshCore app on your phone
  3. Navigate to any channel you've configured
  4. Type and send: wx London
  5. Wait for the bot's response with weather information!

Method 2: Test Without Radio (Interactive Mode)

python3 weather_bot.py --interactive

Then type commands directly in the terminal:

wx London
wx Manchester
weather York
quit

Method 3: Test Without Radio (One-Shot)

python3 weather_bot.py --location London

This fetches weather and exits immediately (no radio hardware needed).

🎉 Success!

If you see weather data returned, the bot is working correctly! You can now use it on your mesh network.

Troubleshooting

If you encounter issues, check the troubleshooting guide for common problems and solutions.

Quick Fixes

Issue Solution
No serial port found Check USB connection, try ls /dev/ttyUSB*
Bot not responding to messages Ensure radio is subscribed to channels via MeshCore app
Location not found Use full city name or add country: wx York, UK
Wrong city returned Specify country in command: wx York UK
